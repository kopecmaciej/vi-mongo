# Release v0.3.1

<img src="https://github.com/kopecmaciej/vi-mongo/blob/master/assets/logo/no-background.svg" align="center"/>

## What's New

### New Features

- **Configurable History Limit** (by [@thisago](https://github.com/thisago), [#123](https://github.com/kopecmaciej/vi-mongo/pull/123)): New top-level `historyLimit` property in `config.yaml` controls how many entries the history modal keeps. Default stays at 10.

### Bug Fixes

- **History Modal Quick-Select Shortcuts**: Digit shortcuts in the history modal now map correctly to entries 0-9 instead of breaking once more than ten entries were stored.

## Thank You

Thank you to everyone who contributed to and tested this release!
