# Release v0.3.2

<img src="https://github.com/kopecmaciej/vi-mongo/blob/master/assets/logo/no-background.svg" align="center"/>

## What's New

### New Features

- **Per-Connection Read-Only Mode** (by [@theduman](https://github.com/theduman), [#124](https://github.com/kopecmaciej/vi-mongo/pull/124)): New `readOnly` connection option blocks every write path: insert, update, delete, create/drop/rename collection, create/drop index, and aggregations containing `$out` or `$merge`. Toggle it from the checkbox in the connection form; read-only connections are marked with "READ-ONLY" in the header.
- **Auth Source Option** ([#128](https://github.com/kopecmaciej/vi-mongo/issues/128)): New `authSource` connection option lets users defined in another database (e.g. `admin`) authenticate while connecting to a different target database.

### Bug Fixes

- **Windows Log Path**: The log file now goes to the system temp directory instead of a hardcoded `/tmp`, so logging works on Windows.
